## Java Edition

1. Open Minecraft and make sure you are on the version listed below.
2. Press **Multiplayer**, then **Add Server**.
3. Put the server name in the first box and the address in the second:

   ```
   play.emberfell.gg
   ```

4. Press **Done**, then double click the server in the list.

If the server was asleep, the first join takes a few seconds while it wakes
up. Try once more and you will be in.

## Bedrock, phones and consoles

Add a server with the address above and port `19132`. On a console you may
need a third party app to add servers; the Discord has the current guide.

## Which version

| What | Version |
| --- | --- |
| Minecraft | 1.21.8 |
| Loader | Fabric |

Older clients are turned away with a message telling you which version to use.

## The first ten minutes

- Read the [rules](/rules/) before you build anything.
- Spawn is protected. Walk a few hundred blocks before you settle down.
- `/sethome` sets a home, `/home` takes you back.
- Ask in chat if you are stuck. Somebody usually answers.
