## What the server runs

| Mod | What it does |
| --- | --- |
| Fabric API | What everything else needs |
| Lithium | Makes the server run faster without changing anything |
| FerriteCore | Uses less memory |
| Chunky | Pre-generates the world so exploring is smooth |

You do not need to install any of these. They run on the server only.

## Client mods you may use

These change what you see, not what you can do:

- **Sodium** and **Iris** for frame rate and shaders
- **Mod Menu** for tidying your options
- **AppleSkin**, **Xaero's Minimap** (cave mode off), **Inventory Profiles Next**

## Client mods you may not use

- X-ray, cave finders and anything that shows ores through stone
- Fly, speed, reach, kill aura and the rest of the combat helpers
- Auto-fishing, auto-clickers and anything that plays while you are away
- Minimaps with cave mode or entity radar turned on

We check, and the checks are not the interesting part of this server. Play it
straight.

## Asking for a mod

Open a thread in the Discord. Say what the mod does and why it makes the
server better. Server side mods that everyone benefits from get considered
every time.
